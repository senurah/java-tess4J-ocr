# Contributing to Java OCR CLI Tool using Tess4J

Thank you for your interest in contributing to this project! Your contributions help improve the tool for everyone.

## How to Contribute

We welcome contributions in the following forms:

- Bug reports and issue submissions
- Feature requests
- Code contributions (new features, bug fixes, refactoring)
- Documentation improvements

## Getting Started

1. **Fork the Repository**  
   Click the "Fork" button on the top right of the [repository page](https://github.com/senurah/java-tess4J-ocr).

2. **Clone Your Fork**
 ```bash
   git clone https://github.com/your-username/java-tess4J-ocr.git
   cd java-tess4J-ocr
```
3. **Create a New Branch**
 ```bash
  git checkout -b feature/your-feature-name
```
4. **Make Your Changes**  
   Be sure to follow the existing code style and structure. Include tests if relevant.

6. **Test Your Changes**  
   Make sure the project builds and runs correctly before submitting your contribution.

7. **Commit and Push**
```bash
git add .
git commit -m "Add feature: your feature description"
git push origin feature/your-feature-name
```
8. **Open a Pull Request**  
   Go to the original repository and click "New Pull Request". Choose your fork and branch.

## Code Guidelines

- Use meaningful commit messages.
- Keep pull requests focused and minimal.
- Follow Java best practices and ensure code readability.
- Include comments where necessary.

## Reporting Issues

If you encounter a bug or have an idea for improvement:

1. Search existing [issues](issues) to avoid duplicates
2. Open a new issue with a clear description and steps to reproduce (if applicable).

## Code of Conduct

By contributing, you agree to follow our Code of [Conduct](Conduct) and maintain a respectful and constructive community.
