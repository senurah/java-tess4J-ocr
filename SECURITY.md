# Security Policy

The table below shows which versions of the project are currently supported with security updates.

| Version         | Supported          |
| --------------- | ------------------ |
| 1.0.x           | :white_check_mark: |
| < 1.0           | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please follow the process below:

1. **Do not create a public issue** if the vulnerability is sensitive.
2. Contact the maintainer directly via email: [neophytetoskill@gmail.com](mailto:neophytetoskill@gmail.com)
3. Please include:
   - A detailed description of the issue
   - Steps to reproduce it, if possible
   - Any relevant logs or error messages
4. You will receive an acknowledgment within **48 hours**.
5. If the vulnerability is confirmed, a fix will be prioritized and rolled out as soon as possible, with appropriate credit (if desired).

We take all reported vulnerabilities seriously and are committed to ensuring the security and privacy of users relying on this tool.
